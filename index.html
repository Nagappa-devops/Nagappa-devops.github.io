AWS multi-account inventory

Internal tooling
AWS, Lambda, Apps Script

Problem
Resource data from 9 production AWS accounts had to reach one Google Sheet, and the Lambda response hit the 6 MB payload limit.
What I built
A Lambda that scans the accounts and an Apps Script that writes to the sheet. A chunked fetch (a manifest call, then one call per account) replaced the single large response. Time-field normalization stops timestamp-only changes from marking rows as updated.
Result
The payload limit no longer blocks the scan, and the sheet shows genuine changes only.
